Privacidade

O JaMi Protect é atualmente uma prévia estática no GitHub Pages. Mantemos a coleta de dados deliberadamente pequena e não usamos publicidade nem rastreadores de analytics próprios do JaMi neste site.

O que este site coleta

O JaMi Protect não define cookies de analytics nem cria perfis de publicidade nesta prévia estática. A hospedagem do GitHub Pages pode registrar endereços IP dos visitantes para fins de segurança; o GitHub trata esses dados de acordo com sua própria política de privacidade.

E-mails de contato e avaliações

Se você entrar em contato com o JaMi Protect ou enviar o formulário de avaliação, seu aplicativo de e-mail envia diretamente as informações que você escolher incluir. Seu endereço de e-mail é usado para conversa, suporte ou feedback e não é exibido em uma avaliação pública.

Avaliações públicas

Uma avaliação só pode ser publicada quando você selecionar explicitamente a opção de consentimento. Depois, você pode retirar o consentimento para futuras exibições públicas entrando em contato com o JaMi Protect.

Finalidade e retenção

Informações de contato e feedback são usadas para responder mensagens, avaliar feedback e, somente com consentimento, preparar uma avaliação pública da comunidade. Devem ser mantidas apenas pelo tempo razoavelmente necessário para esses fins ou para uma solicitação relacionada.

Serviços de terceiros

Este site é hospedado pelo GitHub Pages. Links externos como Steam, SteamGridDB e GitHub têm suas próprias práticas de privacidade.

Suas escolhas

Você pode usar o site sem enviar um formulário. Pode solicitar correção ou exclusão de informações enviadas anteriormente pelo endereço de contato na página Contato.
