O que a JaMi verifica

Estas são as primeiras áreas de medição que a JaMi verifica antes de recomendar uma mudança para este jogo.

  • Frame pacing / 1% lows
  • CPU headroom during active gameplay
  • Latency / high-refresh consistency
  • Background CPU contention

Direção dos ajustes

Estas áreas merecem testes separados em vez de ficarem escondidas em um preset genérico.

  • Frame-rate limit
  • Latency / reflex-style options
  • Shadows / effects
  • Render scale
