Resumen de investigación de rendimiento JaMi

Para Roblox, JaMi sigue carga de CPU Alta, carga de GPU Variable, sensibilidad de VRAM Variable y enfoque de frame pacing Media. Este perfil evidence-ready es una base de investigación, no una promesa de FPS. Los ajustes se mantienen separados para poder medir, explicar y revalidar los cambios tras actualizaciones del juego o de controladores.
