Privacidad

Privacidad

JaMi Protect es actualmente una vista previa estática en GitHub Pages. Mantenemos la recopilación de datos deliberadamente mínima y no ejecutamos publicidad ni rastreadores analíticos propios de JaMi en este sitio.

Este sitio recopila

JaMi Protect no establece cookies analíticas ni crea perfiles publicitarios en esta vista previa estática. El alojamiento de GitHub Pages puede registrar direcciones IP de visitantes por motivos de seguridad; GitHub gestiona esos datos según su propia política de privacidad.

Correos de contacto y reseñas

Si contactas con JaMi Protect o envías el formulario de reseña, tu aplicación de correo envía directamente la información que decidas incluir. Tu dirección de correo se utiliza para la conversación, soporte o feedback y no se muestra en una reseña pública.

Reseñas públicas

Una reseña solo puede publicarse cuando seleccionas expresamente la opción de consentimiento. Más adelante puedes retirar el consentimiento para futuras publicaciones contactando con JaMi Protect.

Finalidad y conservación

La información de contacto y feedback se usa para responder mensajes, evaluar comentarios y, solo con consentimiento, preparar una reseña pública de la comunidad. Debe conservarse únicamente durante el tiempo razonablemente necesario para esos fines o una solicitud relacionada.

Servicios de terceros

Este sitio está alojado en GitHub Pages. Los enlaces externos como Steam, SteamGridDB y GitHub tienen sus propias prácticas de privacidad.

Tus opciones

Puedes usar el sitio web sin enviar ningún formulario. Puedes solicitar la corrección o eliminación de información enviada anteriormente mediante la dirección de contacto de la página Contacto.
