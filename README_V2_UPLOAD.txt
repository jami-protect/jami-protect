JAMI PROTECT WEBSITE V2 - DYNAMIC
=================================

UPLOAD
1. Extract this ZIP.
2. Open the GitHub repository.
3. Add file -> Upload files.
4. Upload ALL files/folders from this package to the repository root.
5. Allow GitHub to replace the existing V1 files.
6. Commit changes.
7. GitHub Pages will redeploy automatically.
