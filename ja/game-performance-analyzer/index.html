FAQ

よくある質問

JaMiは特定のFPS向上を保証しますか？

いいえ。性能はゲーム、パッチ、ハードウェア、ドライバー、設定、負荷によって変わります。JaMiは一律の割合ではなく状況を測定します。

Windows Securityやanti-cheatを無効にしますか？

製品方針はWindowsの保護を維持し、anti-cheat回避を行わないことです。高リスク変更は明示的な安全ゲートを必要とします。

なぜゲーム別ページも必要ですか？

エンジン、パッチ、renderer、設定ごとに挙動が異なるためです。ゲームプロフィールが診断に必要な文脈を与えます。

ゲームを最適化。PCを保護。

変更する前に、JaMi ProtectであなたのPCに本当に重要な要因を理解します。
