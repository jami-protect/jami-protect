Privacy

Datenschutz

JaMi Protect ist derzeit eine statische GitHub-Pages-Vorschau. Die Datenerhebung wird bewusst klein gehalten; eigene Werbe- oder Analytics-Tracker werden nicht eingesetzt.

Welche Daten diese Seite erfasst

JaMi Protect selbst setzt keine Analytics-Cookies und erstellt keine Werbeprofile. GitHub Pages kann IP-Adressen von Besuchern zu Sicherheitszwecken protokollieren; GitHub verarbeitet diese Hosting-Daten nach der eigenen Datenschutzerklärung.

Kontakt- und Review-E-Mails

Wenn du JaMi Protect kontaktierst oder das Review-Formular nutzt, sendet dein E-Mail-Programm die gewählten Angaben direkt per E-Mail. Deine E-Mail-Adresse wird für die Unterhaltung, Support oder Feedback verwendet und nicht in einer öffentlichen Review angezeigt.

Öffentliche Reviews

Eine Review kann nur öffentlich veröffentlicht werden, wenn du die Veröffentlichungs-Einwilligung ausdrücklich auswählst. Diese Einwilligung kann für eine zukünftige Anzeige später widerrufen werden.

Zweck und Aufbewahrung

Kontakt- und Feedbackdaten werden genutzt, um Nachrichten zu beantworten, Feedback auszuwerten und, nur mit Einwilligung, eine öffentliche Community-Review vorzubereiten. Daten sollen nur so lange aufbewahrt werden, wie sie dafür vernünftigerweise benötigt werden.

Drittanbieter

Diese Website wird über GitHub Pages gehostet. Externe Links wie Steam, SteamGridDB und GitHub haben eigene Datenschutzpraktiken.

Deine Wahlmöglichkeiten

Du kannst die Website nutzen, ohne ein Formular abzusenden. Über die Kontaktseite kannst du die Berichtigung oder Löschung zuvor gesendeter Informationen anfordern.
