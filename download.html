How to activate the button

One small setting when your installer exists.

  1. Create a GitHub Release in timmiejtwitch-sketch/jami-protect.
  2. Upload the installer using the exact public filename JaMiProtect_Setup.exe.
  3. Open assets/js/config.js.
  4. Change releaseReady: false to releaseReady: true.
  5. Commit the change. The landing page can then point directly to the latest installer.
