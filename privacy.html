Privacy

Privacy

JaMi Protect is currently a static GitHub Pages preview. We keep data collection deliberately small and do not run JaMi-owned advertising or analytics trackers on this site.

What this site collects

JaMi Protect itself does not set analytics cookies or build advertising profiles on this static preview. GitHub Pages hosting may log visitor IP addresses for security purposes; GitHub handles that hosting data under its own privacy statement.

Contact and review emails

If you contact JaMi Protect or submit the review form, your email application sends the information you choose to include directly by email. Your email address is used for the conversation, support or feedback and is not shown in a public review.

Public reviews

A review is only eligible for public publication when you explicitly select the publication-consent option. You can later withdraw consent for future public display by contacting JaMi Protect.

Purpose and retention

Contact and feedback information is used to answer messages, evaluate feedback and, only with consent, prepare a public community review. It should be kept only as long as reasonably needed for those purposes or a related request.

Third-party services

This site is hosted by GitHub Pages. External links such as Steam, SteamGridDB and GitHub have their own privacy practices.

Your choices

You can use the website without sending a form. You can request correction or deletion of information you previously sent via the contact address on the Contact page.
